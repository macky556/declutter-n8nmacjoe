# declutter-n8nmacjoe

This repository deploys an **n8n automation server** on **Render.com** using Docker.

## Deployment Guide

1. Create a GitHub repo named `declutter-n8nmacjoe`
2. Upload all files
3. Go to Render → New Web Service → Choose Docker
4. Deploy
5. Access your n8n dashboard:
   https://declutter-n8nmacjoe.onrender.com
